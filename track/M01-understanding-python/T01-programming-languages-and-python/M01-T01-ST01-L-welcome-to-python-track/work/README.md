What is programming?
 Programming is the process of understanding a problem and creating step-by-step instructions that a computer can follow to solve it.

Question 2: What is a programming language?
 A programming language is a formal language used to write instructions that computers can understand and execute.

Question 3: Is Python the same as programming?
 No. Programming is the overall problem-solving process, while Python is one programming language used to implement solutions.

Question 4: What is syntax?
 Syntax is the set of rules that define how code must be written in a programming language.

Question 5: Can the same algorithm be written in Python and Java?
 Yes. The logic remains the same, but the syntax differs between languages.

Question 6: Which comes first: understanding the problem or writing Python syntax?
 Understanding the problem comes first. The solution logic is developed before writing the code.

Question 7: What remains the same when one solution is written in different programming languages?
 The problem, inputs, rules, logic, algorithm, and expected output remain the same.

Question 8: Can someone know Python syntax but still struggle to solve problems? Explain why.
 Yes. Knowing syntax only means understanding how to write code. Problem-solving requires analyzing the problem, designing logic, creating algorithms, and thinking critically to find solutions.
